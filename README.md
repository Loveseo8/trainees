# Каталог тренеров ИНГАЛ

Статический PWA-сайт без серверной части. Для публикации загрузите всю папку на Vercel, GitHub Pages или другой статический хостинг.

Данные находятся в `data/trainers.js`. На публичную страницу не перенесены телефоны, электронные адреса, даты рождения, паспортные данные и гонорары из исходной таблицы.

Актуальная версия данных загружена из `Untitled spreadsheet (1).xlsx`. В каталог включены строки со статусом «работает». Тренер относится к федеральным, если в поле «Регион» отдельным значением указано «РФ» или в поле «Статус тренера» присутствует слово «национальный»; остальные действующие тренеры относятся к региональным.

Интерактивная карта использует amCharts 5 через CDN. Субъекты внутри одного федерального округа визуально объединены общим цветом без внутренних линий. При наведении целиком подсвечиваются только округа, в которых есть тренеры выбранного направления. Подсказка показывает только сокращение округа без названия субъекта. Клик по округу фильтрует тренеров; при выборе пустого округа боковая панель остаётся без карточек. Городские точки уточняют выбор. Если библиотека недоступна, сайт автоматически показывает выбор города кнопками.
